# Bank-backend

Усі команди розробки та розгортання зібрані в одному `Makefile`:

```sh
make help
```

## Swagger

Після запуску застосунку Swagger UI доступний за адресою:

```text
http://localhost:8080/swagger/index.html
```

Повторна генерація документації після зміни HTTP handler-анотацій:

```sh
make swagger
```
